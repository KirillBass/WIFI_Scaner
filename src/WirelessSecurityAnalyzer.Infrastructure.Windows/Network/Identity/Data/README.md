# Локальная база производителей

`oui.tsv` содержит 58 242 публичных назначения MAC-префиксов длиной 24, 28 и 36 бит.
Формат: HEX-prefix, tab, полное название зарегистрированной организации, LF.
Длинное тире в названии организации заменено обычным дефисом.
Используется наиболее длинное совпадение. Групповые и locally administered префиксы исключены.

Источник фактических назначений: [IEEE Registration Authority](https://standards.ieee.org/products-programs/regauth/).
Полученный снимок: [публичная база Wireshark](https://www.wireshark.org/download/automated/data/manuf.gz),
загружена 2026-10-08; заголовок снимка: TShark 4.7.5rc0-1-gc16ca0c3.
Прямой сервер IEEE возвращал HTTP 418, поэтому использован этот полный публичный снимок.
Использованы только префиксы и полные названия организаций, без кода Wireshark.

SHA-256 `oui.tsv`: `e6bffa1d1c1a2cf0b18598567b6c22a8869b1c1bd6435386dceecec023833de6`.

Файл включён в сборку как embedded resource `WirelessSecurityAnalyzer.Oui.tsv`.
Во время работы приложения база не загружается и не обновляется через интернет.
Для обновления разработчик заменяет снимок в исходниках и собирает приложение заново.

OUI указывает зарегистрированного владельца адресного блока, часто производителя сетевого чипа,
и не доказывает марку готового устройства. Например, `04:EC:D8` в этом снимке - Intel Corporate,
`10:A3:B8` - Iskratel d.o.o.; примеры Samsung/TP-Link из ТЗ не используются как фактические назначения.
Private MAC не проверяется по OUI. Явный UPnP manufacturer имеет приоритет над OUI.
